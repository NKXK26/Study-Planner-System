# Student Study Planner v1.1.1

This Windows desktop update fixes PDF colour extraction and improves startup reliability.

- Extract colours from searchable study planner PDFs using the bundled runtime. Python is no longer required.
- Load the PDF worker and fonts from the app, including offline.
- Restore unit names and credit information from the database during planner import.
- Start the desktop server on an available port when port 3000 is already in use.
- Include static assets in desktop development builds and save startup errors to the desktop log.

The desktop compatibility checks included an offline two-page PDF upload, 29 regression suites and 391 HTTP integration assertions. The installer is for 64-bit Windows.
